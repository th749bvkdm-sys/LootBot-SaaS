# تقرير تنفيذ غرفة المعلم ومظاهر المتجر

تاريخ المراجعة: 10 أكتوبر 2026. العمل داخل تطبيق LootBot الحالي؛ ملفات العرض التقديمي لم تُعدّل. التغييرات محلية ولم تُنفذ عملية commit أو push أو نشر أو ترحيل لقاعدة الإنتاج.

## ما أُضيف

| الجزء | التنفيذ |
| --- | --- |
| نوع الحساب | اختيار تاجر أو معلم للحساب الجديد، محفوظ على الخادم، مع استئناف الإعداد. الحسابات السابقة تبقى تجارًا، وصلاحية Super Admin مستقلة. |
| إعداد المعلم | معالج محفوظ متعدد الخطوات لبيانات المعلم والمدرسة والمواد والفصول وتفضيلات الطباعة والشعار الاختياري، مع تحرير لاحق في الإعدادات. |
| غرفة المعلم | لوحة من البيانات الفعلية، فصول وكشوف خاصة، حضور، درجات، واجبات، تحضير، بنك أسئلة، تقارير، قوالب، تذكيرات وإعدادات. |
| الطلاب | إضافة وتحرير، CSV مع تعيين الأعمدة ومعاينة الأخطاء والتطابقات وخيار الإضافة أو التحديث، بحث وفرز وصفحات واختيار جماعي، أرشفة واسترجاع وحذف قابل للاسترجاع، نقل يحتفظ بالمعرف والتاريخ، وملف الطالب الخاص. |
| الحضور والدرجات | حفظ حسب الفصل والتاريخ، تقييمات فردية ودرجات جماعية داخل معاملة واحدة، قوالب سجل درجات محفوظة لكل فصل. |
| المهام والتحضير | حفظ المواعيد وحالة المهمة وتسليم الطلاب، خطط دروس قابلة للتعديل والتكرار والطباعة، وأسئلة محفوظة قابلة لإعادة الاستخدام. |
| محرر الاختبار | حقول وعناوين وأسئلة وخيارات ودرجات ومساحات إجابة قابلة للتحرير؛ إضافة ونسخ وترتيب وتجميع الأسئلة، تراجع وإعادة، حفظ تلقائي ظاهر، حماية تعارض النسخ، نسخ مستقلة وقوالب وإعادة فتح. |
| الصور | رفع JPEG/PNG/WebP خاص بالحساب، حفظ المصدر الأصلي منفصلًا، قص وتدوير وتسوية وإضاءة وتباين، عرض المصدر بجانب المحتوى، ومراجعة صريحة للنص. |
| الطباعة | ثلاثة تصاميم مستقلة عن المحتوى: رسمي، مناسب للابتدائية، واقتصادي. معاينة A4، تقسيم مقاس للأسئلة مع فواصل يدوية، كشف السؤال الأكبر من الصفحة، وتصدير PDF عبر طباعة المتصفح. |
| الأتمتة | عامل فعلي يعمل مع API: مواعيد قريبة، متابعة الغياب، درجات غير مرصودة، ملخص أسبوعي، مسودات وتذكيرات دورية؛ تشغيل وإيقاف وتعديل ونسخ وحذف، نتائج وأخطاء وسجل تنفيذ وعدم تكرار. التذكيرات داخل التطبيق فقط. |
| المتاجر | داكن وأبيض وLootBot Nebula، معاينة بالمنتجات المنشورة الفعلية، حفظ لكل متجر، كتالوج وتصنيفات وتفاصيل متسقة. العرض العام معطل افتراضيًا ويحتاج تفعيل التاجر. |
| التصميم | واجهة عربية RTL، أسطح زجاجية داكنة مقروءة، شعار L هندسي SVG موحد في المواقع الرئيسية وأيقونة المتصفح، دعم الشاشات المختلفة والتركيز ولوحة المفاتيح وتقليل الحركة. |

لم تُضف رسائل لأولياء الأمور، أو بوابة دفع، أو تجربة شراء جديدة داخل تيليجرام. بقيت وظائف التاجر القائمة، وأصلحت قراءات إعدادات داخل معاملات النشر والمكافآت لكي تستعمل اتصال المعاملة نفسه.

## قاعدة البيانات والتشغيل

الترحيل `0010` يضيف نوع الحساب وجداول المعلم وقيود الملكية والفهارس، دون حذف بيانات التاجر. جُرّب على مخطط محلي يحاكي البنية السابقة، ثم أُعيد تطبيقه للتحقق من قابلية التكرار وبقاء التاجر السابق كتاجر. يُختار النوع مرة واحدة؛ تبديل الحساب بين النوعين غير مدعوم حاليًا.

يحتاج التشغيل إلى `DATABASE_URL` للخادم ومتغيرات المشروع المعتادة. لا توجد مفاتيح جديدة مطلوبة للتحرير اليدوي. أوامر المشروع من الجذر:

```text
node scripts/run-pnpm.mjs run typecheck
node scripts/run-pnpm.mjs run lint
node scripts/run-pnpm.mjs run build
node scripts/run-pnpm.mjs run dev
```

لبناء المستودع كاملًا، يحتاج مشروع `mockup-sandbox` القائم إلى `PORT` و`BASE_PATH` في بيئة البناء. في PowerShell، ضُبطا أثناء التحقق إلى `$env:PORT='5192'` و`$env:BASE_PATH='/'` قبل أمر البناء. لا يحتاج محرر المعلم إلى خدمة مستقلة.

يجب تطبيق الترحيل في قاعدة التشغيل المعتمدة قبل إتاحة الميزة. لم يُطبّق على خدمة فعلية في هذه المهمة. تعليمات `TEACHER_ROOM.md` تتضمن اختبارًا محليًا مؤقتًا يمكن تشغيله دون قاعدة مستخدمين حقيقية.

## OCR وما يتطلب إعدادًا خارجيًا

الوضع العامل افتراضيًا يدوي: صورة أصلية خاصة، أسئلة قابلة للتحرير، مراجعة وحفظ وطباعة. لا تُعرض نتيجة استخراج وهمية.

يتوفر محول اختياري إلى Azure Vision Read 3.2، مع اختبار طلبات واستجابات محاكاة، والتحقق من مصدر رابط الاستجابة ومهلة المعالجة. لتمكينه تُضبط على الخادم فقط:

```text
TEACHER_OCR_PROVIDER=azure-read
TEACHER_OCR_ENDPOINT=https://<resource>.cognitiveservices.azure.com/
TEACHER_OCR_KEY=<server-secret>
```

لم يُختبر حساب Azure فعلي أو دقة استخراج صور عربية حقيقية. الأسطر المستخرجة قابلة للتحرير وتحتاج مراجعة؛ لا يخمن المحول الإجابات أو الدرجات أو البنية التعليمية. لا تحفظ المفاتيح في الشفرة أو متغيرات `VITE_*`. الخدمة الخارجية قد تتطلب رسومًا، وتستقبل الصورة عند طلب الاستخراج.

## الخصوصية وحدود التنفيذ

- تحقق الجلسة والملكية ونوع الحساب على الخادم، وCSRF لكل كتابة، وقيود رفع وحجم وأبعاد الصور.
- صور الاختبارات والشعارات الخاصة تُقرأ عبر جلسة الحساب ولا تُنشر كرابط ملفات عام. بيانات الطالب وملاحظاته لا تُضاف إلى روابط البحث أو التقارير العامة.
- CSV يحافظ على العربية ويعالج الأرقام العربية والغربية، ويحيّد صيغ الجداول عند التصدير. Excel يُحوّل إلى CSV UTF-8؛ لم يضف التطبيق قارئ XLSX أو مدخل PDF.
- عامل التذكيرات يعمل كل دقيقة أثناء تشغيل API؛ ساعات الجدولة UTC. الاستضافة التي تنام تعالج المستحقات بعد استئناف الخادم.
- تذكير المواعيد المرتبط بفصل يفحص واجباته ومهامه. اختيار جميع الفصول يشمل الاختبارات أيضًا؛ الاختبار يحتفظ بوصف صفه على الورقة ولا يملك ارتباط فصل ثابتًا في قاعدة البيانات.
- الاختبارات استعملت بيانات وهمية وقاعدة PostgreSQL محلية مؤقتة عبر PGlite. ليست تحققًا من تنافس عدة خوادم إنتاج. تعذر استخدام فرع Neon المعزول بسبب رفض بيانات اتصاله؛ لم يُستبدل بقاعدة الإنتاج.
- جرى اختبار Chromium/Edge وأحجام جوال وآيباد وحاسوب، وليس أجهزة iOS أو متصفح Safari فعليًا.
- المرفق المتاح لهذا الطلب ملف نصي فقط؛ لم توجد صورة المرجع التصميمي المشار إليها فيه. استُخدم وصف التصميم المكتوب، ولم يُدّعَ مطابقة صورة غير متاحة.

تقارير الاختبارات ولقطات البيانات الوهمية موجودة في `artifacts/lootbot/test-results/{teacher,teacher-exam,storefront}`. يشمل التحقق إنشاء PDF A4 للكشف وللاختبار؛ لا تكفي صورة واجهة الطباعة وحدها لإثبات ملف PDF.

المجموع: 142 اختبارًا وحدويًا وHTTP، و26 مجموعة اختبار متصفح، جميعها ناجحة. اختبارات المتصفح النهائية استعملت الواجهة المبنية للتشغيل، دون خادم HMR. روجعت بصريًا صور مستخرجة من PDF النهائي لصفحات الاختبار الثلاث، ومن ملفات PDF للتصاميم الثلاثة، ومن كشف الطلاب ذي الصفحة الواحدة: العناوين المتكررة والعربية والهوامش وترقيم «الصفحة … من …» ظاهرة وسليمة. ملفات `final-20261010-*.png` و`final-visual-verification.json` توثق فحص الاختبار النهائي.

صدرت تحذيرات بناء غير مانعة: تعذر تحديد مصدر sourcemap في مكون `ui/tooltip.tsx` القائم، وحجم حزمة الدخول نحو 504 كيلوبايت قبل gzip. وحدات المعلم ومحرر الاختبار تُحمّل عند الحاجة في حزم منفصلة. لم تُخفَ التحذيرات بتغيير حدود التحذير.

## الخطوة التالية

مراجعة التغييرات ثم تجربة الترحيل والتطبيق على بيئة اختبار PostgreSQL مستقلة معتمدة. بعد الموافقة على الإتاحة يمكن استخدام مسار نشر المشروع الحالي. تفعيل OCR اختياري ومنفصل عن تشغيل أدوات المعلم اليدوية. النشر الفعلي وتحديث GitHub متوقفان وفق تعليماتك.
