الكيمياء تعتمد حزمة `chemistry-v1.json` ونماذج من [OpenStax Chemistry 2e، تصنيف التفاعلات](https://openstax.org/books/chemistry-2e/pages/4-2-classifying-chemical-reactions). اختبارات حفظ الذرات ومطابقة المعادلات ناجحة؛ المراجعة التربوية البشرية للمنهج **معلقة**. النماذج تعليمية رمزية، وليست وصفات تجارب عملية أو محاكاة pH أو معدل تفاعل كمي. الحزمة لا تتغير بصمت للإسنادات القائمة؛ تشغيل نسخة حزمة غير مطابقة يُرفض.

## قاعدة البيانات والإعدادات

الترحيلات الأمامية `0010_teacher_room.sql` ثم `0011_teacher_learning.sql` ثم `0012_teacher_tools.sql` ثم `0013_teacher_simulations.sql` تضيف نوع الحساب، رموز وجلسات الطلاب، الأنشطة ونسخها وإسناداتها وسجل أحداثها، نسخ الأسئلة، مراجعات السجلات وكشوف الفصل ومشاركة القوالب. تشمل قيود ملكية وفهارس ومفاتيح خارجية. اختُبرت محليًا على مخطط سابق مع تاجر محفوظ؛ 0010–0012 طُبقت مرتين مباشرة، وسجل الترحيلات اختُبر لمنع إعادة التطبيق وتغيير البصمة والرجوع عند فشل SQL.

التشغيل يحتاج `DATABASE_URL` لقاعدة مصرح بها. لا توجد مفاتيح جديدة لازمة للتحرير اليدوي أو الدروس أو الكيمياء. OCR الاختياري الموجود يستخدم:

```dotenv
TEACHER_OCR_PROVIDER=azure-read
TEACHER_OCR_ENDPOINT=https://<resource-name>.cognitiveservices.azure.com/
TEACHER_OCR_KEY=<server-secret>
```

هذه متغيرات خادم، وليست `VITE_*`. غيابها يبقي التحرير اليدوي فعالًا ويعرض الحالة بصدق. اختُبر بروتوكول الموصل والأخطاء ببديل محلي؛ لم يُختبر حساب Azure حقيقي أو دقة استخراج ورقة عربية فعلية. لا تضع الأسرار في الشفرة.

العامل الموجود يعمل داخل API؛ `TEACHER_WORKER_DISABLED=true` لتعطيله في الاختبارات. التذكيرات داخل التطبيق فقط. استمرار التوقيت يحتاج خادمًا مستيقظًا؛ وقت الجدولة الحالي UTC ومبين في الواجهة، والإجازات يحددها المعلم.

## إعادة التشغيل والتحقق

من جذر المشروع، باستخدام Node المتاح وpnpm المحدد للمشروع:

```powershell
node scripts/run-pnpm.mjs run dev
```

للبناء الكامل، يحتاج sandbox القائم `PORT` و`BASE_PATH`:

```powershell
$env:PORT='5192'
$env:BASE_PATH='/'
node scripts/run-pnpm.mjs run build
```

لا تشغّل تطوير API على قاعدة إنتاج للاختبار. لا تنفذ ترحيلًا قبل اعتماد البيئة المقصودة. أمر الترحيل الحالي، عند اعتماد قاعدة التطوير/الاختبار، هو `node scripts/run-pnpm.mjs run db:migrate`؛ لم يُنفذ ضد الإنتاج في هذه المهمة.

للتحقق دون قاعدة خارجية، من `artifacts/api-server`:

```powershell
node --test src/lib/*.test.mjs
node tests/run-teacher-local.mjs tests/teacher-integration.ts
node tests/run-teacher-local.mjs tests/learning-integration.ts
node tests/run-teacher-local.mjs tests/teacher-tools-integration.ts
node tests/run-teacher-local.mjs tests/storefront-integration.ts
node tests/run-teacher-local.mjs tests/api-integration.ts
node tests/run-teacher-local.mjs tests/migration-ledger-local.ts
node tests/run-teacher-browser-local.mjs teacher-tools-browser.mjs learning-browser.mjs teacher-browser-acceptance.mjs teacher-exam-browser.mjs storefront-browser.mjs
```

اختبارات المتصفح الحالية تحتاج Playwright وpdf-lib في مسار runtime المحلي وEdge. `tests/verify-print-pdfs.py` يحتاج Python مع pypdf وPoppler لفحص ملفات الطباعة الناتجة وإعادة رسمها. هذه أدوات اختبار، ولا تدخل حزمة تطبيق العميل.

## الاستخدام

1. حساب المعلم يدخل إعداداته ويختار تصميم الطباعة والتقريب والقالب المحفوظ إن وجد.
2. من «الدروس التفاعلية»، يؤلف أو يستورد سؤالًا، يراجع، ينشر نسخة ثابتة، ثم يسندها إلى فصله. يولد رموز الفصل والطلاب ويحفظ بطاقاتها بشكل خاص.
3. الطالب يدخل من `/learn` بالرمزين ويرى أنشطته وحده. النتائج تظهر للمعلم في الدروس؛ يمكن حفظ متابعة بعد تعديلها ومراجعتها.
4. من «السجلات والمخطط والتقييم» يستخدم مخطط A/B/C والمعايير والسجلات وأوراق العمل وبطاقات الخروج وخزانة الموارد والتقويم وشبكة الدرجات والخصوصية.
5. من «مختبر الكيمياء» يختار نموذجًا محددًا ويعاينه، ثم ينشئ النشاط لإسناده. حالة المراجعة ومصدره وحدوده ظاهرة.

## الحدود المتبقية

- PDF كمدخل وXLSX غير مفعّلين؛ الصور JPEG/PNG/WebP وCSV/TSV والتحرير والطباعة اليدوية تعمل. نص الملف يسمح بهما فقط عند وجود معالجة موثوقة.
- OCR الحقيقي يحتاج حسابًا وإعدادات خارجية، ولا يوجد تقييم آلي للمقالات أو ادعاء استخراج كامل للجداول والإجابات.
- لا تصدير DOCX مخصص؛ المستندات قابلة للتحرير في التطبيق مع طباعة المتصفح وتصدير JSON الخاص.
- مشاركة القوالب تنقل الهيكل الآمن فقط مع نسبة مصدر مستعارة ونسخة وتاريخ، وتُجرد النصوص والمراجع والفصل لمنع تسريب الطلاب.
- فحوص الهدف المتتابعة تعرض أدلة ومحاولات فعلية؛ لم تُبن معايرة تربوية لتكافؤ أسئلة مختلفة أو مقياس إتقان رسمي.
- نطاق الكيمياء صغير والمراجعة المنهجية البشرية لازمة قبل اعتماده في التدريس. مراحل بقية المواد C–E وميزات P2 لم تُبن، وفق ترتيب الملف وعدم الوعد بكل المواد دفعة واحدة.
- لم يُجر اختبار أداء على شبكة جوال مدرسية فعلية؛ الحزم كسولة والرسوم SVG، واختُبر الانقطاع والاستئناف محليًا.
- لا تظهر هذه التوسعة على رابط الإنتاج حتى اعتماد التغييرات وترحيل قاعدة البيئة المقصودة ثم النشر المصرح به. هذه الخطوات لم تُنفذ.
