# تقرير تنفيذ التوسعة التعليمية

التاريخ: 13 أكتوبر 2026. المصدر: `codex-education-platform-spec (1).md`، قُرئ كاملًا قبل التنفيذ.

## مكان العمل وحالة التسليم

التغيير موجود في checkout محلي مستقل `LootBot-SaaS-glass-release`، على الفرع `codex/education-platform` المبني على `2fc10bf`. بقي checkout المشروع الأصلي وتعديلاته المحلية محفوظًا. هذه التوسعة لم تُعمل لها commit أو push ولم تُنشر ولم تتصل بقاعدة الإنتاج.

المعاينة الحالية على `http://127.0.0.1:5191`، بخادم Express الفعلي وقاعدة PostgreSQL مؤقتة محلية باستخدام PGlite. حسابات المدرسة والمعلم والطلاب وأسئلة المعاينة مُعلّمة كبيانات محلية. الدرجات لا تُزرع: جرى إنشاء النتيجة الظاهرة بالإجابة من المتصفح، وتُحفظ عبر API.

## قاعدة البيانات ومتغيرات البيئة

الترحيل `0014_education_platform.sql` يضيف جداول education_*، وحقل suspended، ويوسع قيد account_type. لا يحذف بيانات المتاجر أو كشوف المعلمين. يُطبق باستخدام `pnpm db:migrate` في قاعدة محلية/مخوّلة. تحقق الاختبار من تطبيقه مرتين وحفظ التاجر السابق.

متغيرات البيئة دون أسرار:

- `DATABASE_URL`: قاعدة PostgreSQL المخوّلة. المعاينة تُنشئ اتصالًا محليًا مؤقتًا بنفسها.
- `SESSION_SECRET`: إعداد المصادقة الحالي، يُحفظ في البيئة.
- `EDUCATION_DISABLED`: تعطيل أقسام التعليم عند الحاجة.
- `DB_POOL_MAX`: الافتراضي 10؛ الاختبار المحلي يستخدم 1.
- `EDUCATION_BOOTSTRAP_EMAIL`: بريد الحساب المسجل الذي يُهيّأ كأول مدير فقط؛ فارغ في المثال.
- `PORT` و`BASE_PATH`: إعدادات البناء والتشغيل الحالية عند بناء monorepo كاملًا؛ استخدمنا `PORT=5192` و`BASE_PATH=/` للبناء المحلي، دون تعديل الاستضافة.

لم تُضف مفاتيح AI أو بريد أو كلمات مرور إنتاجية. مسارات `/__preview` توجد في برنامج المعاينة المحمي ببيئة test وقاعدة مؤقتة وتُربط بـ127.0.0.1؛ بحث حزم الإنتاج لم يجدها أو حسابات المعاينة.

## حدود التحقق والنواقص الصريحة

- طلبات HTTP متزامنة لرمز محدود اختُبرت بنجاح؛ PGlite في هذا المشغل يستخدم اتصالًا واحدًا. اختبار التنافس الحقيقي بين عدة اتصالات PostgreSQL مستقلة **لم يُنفذ**. يجب تنفيذه على قاعدة اختبار قبل اعتماد الإنتاج.
- المعاينة مؤقتة، وبياناتها تزول عند إيقافها. ليست رابطًا عامًا أو نشرًا إنتاجيًا.
- استعادة كلمة المرور عبر بريد آمن تحتاج مزود إرسال وسياسة وروابط محدودة العمر؛ لم يُضف زر استعادة يوحي بوجود هذه الخدمة.
- التعليقات التعليمية معطلة؛ لم تُنفذ دورة تعليق ومراجعة/إشراف كاملة. التواصل المتاح إعلانات وبلاغات خاصة.
- retentionDays إعداد محفوظ فقط، ولم يُنفذ حذف تلقائي أو مهمة تنظيف للبيانات الحقيقية.
- لا مزود AI مهيأ، ولا زر مساعد يعمل ظاهريًا، ولا إرسال لبيانات الطلاب لمزود خارجي. التوصيات الحالية قواعد شفافة من النتائج.
- التنبيهات والإعلانات داخل المنصة؛ لا إرسال بريد أو SMS أو إشعارات خارجية في هذه التوسعة.
- التحديات هي مجموعات بإشراف المعلم، نسخة ثابتة ومؤقت ونطاق فصل وتقارير؛ لم يُضف ترتيب علني بين الطلاب أو بطولة متعددة الفصول.
- لم يُختبر Safari/iPhone/Android على أجهزة حقيقية. قياسات الجوال واللوحة تمت في متصفح Chromium المحلي.
- مراجعة القوائم ودورة الاستخدام السابقة لا تعني اختبار كل توليفة ممكنة لكل نموذج أو تنفيذ دورة بريد/نسخ احتياطية على الإنتاج.

## التشغيل وإعادة الاختبار

من checkout التوسعة:

```powershell
pnpm run education:preview
```

يُبنى LootBot ثم تُنشأ القاعدة المؤقتة والخادم المحلي. روابط العرض:

- `/__preview/admin`: المدير الأعلى.
- `/__preview/teacher`: المعلم.
- `/__preview/student`: الطالب النشط.
- `/__preview/manager`: مدير المدرسة.
- `/__preview/content`: مسؤول المحتوى.
- `/__preview/support`: الدعم.
- `/__preview/pending`: طالب ينتظر الموافقة.

كل الروابط تحت `http://127.0.0.1:5191`. تغيير الدور يغير cookies المحلية في التبويبات المفتوحة لنفس الأصل. أرسل `stop` في طرفية المعاينة لإيقافها؛ لا تعتمد على بياناتها لحفظ عمل حقيقي.

إعادة اختبارات HTTP من `artifacts/api-server`:

```powershell
pnpm test
node tests/run-teacher-local.mjs tests/education-integration.ts
node tests/run-teacher-local.mjs tests/teacher-integration.ts
node tests/run-teacher-local.mjs tests/learning-integration.ts
```

## أول مدير ومدرسة وطالب وسؤال

1. بعد إعداد قاعدة مخوّلة والترحيل، سجّل حسابك بالطريقة الحالية. حدد بريد الحساب في `EDUCATION_BOOTSTRAP_EMAIL`، ثم شغّل `node scripts/bootstrap-education-admin.mjs`. يرفض البرنامج التهيئة إذا كان مدير أعلى موجودًا؛ لا يغير كلمة المرور ولا ينشئ حسابًا عامًا.
2. افتح `/admin/education`، أنشئ المدرسة، وأسند حساب مدير المدرسة وحساب المعلم المسجل من المستخدمين.
3. أنشئ/اربط فصلًا بصاحبه ومدرسته؛ أصدر رمزًا من رموز الانضمام بموعد وعدد استخدامات وسياسة موافقة. احتفظ بالنص المعروض مرة واحدة خارج سجل التدقيق.
4. سجل الطالب وحدد نوع حساب طالب، ثم افتح `/student` وأدخل الرمز. غير المرتبط لا يدخل المحتوى المحمي. إن طُلبت موافقة، اعتمد الطلب من نطاق المدرسة/الفصل المخوّل.
5. أضف سؤالًا أصليًا/مرخصًا في محتوى القدرات، وحدد المهارة والبدائل والحل والشرح والمصدر. احفظه للمراجعة ثم انشره بحساب ناشر آخر عند تفعيل المراجعة.
6. افتح الطالب وابدأ تدريبًا أو أسند مجموعة من المعلم. راجع النتيجة ودفتر الأخطاء، ثم تقرير المعلم. يلزم اختبار قاعدة كاملة ونسخة احتياطية ومراجعة هذه النواقص قبل نشر التوسعة بإذن منفصل.
