# جرد المنصة قبل التنفيذ

الفرع المحلي `codex/education-platform` يبدأ من نسخة المظهر الزجاجي `2fc10bf`. لا تُعدّل قاعدة الإنتاج أو إعدادات Railway. النسخة الأصلية ذات التغييرات المحلية محفوظة في مكانها.

## البنية

React 19 + TypeScript + Vite، Express 5، PostgreSQL وDrizzle، جلسات cookies مشفرة البصمة وCSRF، ترحيلات SQL بسجل checksum ومعاملات. اختبارات HTTP محلية باستخدام PGlite؛ لا تحتاج الوصول لقاعدة الإنتاج.

## الموجود فعليًا في الشفرة

| المجال | الوضع قبل التغيير |
|---|---|
| غرفة المعلم | API وقاعدة بيانات للفصول والكشوف والحضور والدرجات والمهام والخطط والأسئلة والاختبارات والقوالب والموارد والتذكيرات |
| اختبارات الطباعة | محرر ووثائق محفوظة وإصدارات وصور خاصة؛ OCR يحتاج إعداد مزود، والتحرير اليدوي متاح |
| أنشطة الطلاب | نسخ منشورة وإسناد لفصول وأحداث إجابات فعلية؛ دخول منفصل برمز الفصل ورمز الطالب، دون حساب مدرسة مسجل |
| الكيمياء | محاكاة تعليمية ومهام محفوظة؛ لا تعد محاكاة كيميائية فيزيائية كاملة |
| إدارة المتاجر | تسجيل ودخول وكتالوج وطلبات وخطط وTelegram؛ خارج نطاق التطوير التعليمي |
| Super Admin | إحصاءات متاجر ومستخدمين وصحة وخطط؛ إدارة المدارس والقدرات غير موجودة |
| المدارس/مديرو المدارس | غير موجودة |
| رموز انضمام محدودة الاستخدام | غير موجودة؛ الرموز الحالية خاصة بنشاط المعلم |
| القدرات ودفتر الأخطاء | غير موجودة |

هذا جرد للشفرة والعلاقات والمسارات الموجودة، وليس إعلانًا عن اختبار كل ميزة إنتاجية. نتائج الاختبارات تُسجّل في تقرير التنفيذ.

## إعادة الاستخدام

تظل `users` و`sessions` مصدر الهوية. تستخدم المدارس نفس `teacher_classes` ونفس كشوف `teacher_students`، ويربط enrollment حساب الطالب بسطر الكشف. تستخدم الأنشطة المنشورة ومسارات التقدم الموجودة. تُضاف جداول `education_*` فقط للمفاهيم الناقصة (المدارس والمنح والرموز والقدرات والخطط والبلاغات)، دون نسخ الكشوف أو الاختبارات أو إنشاء خدمة مستقلة.
