# مصادر الكمي ومراجعة المحتوى

الملفات الثلاثة المرفقة مسجلة في `SOURCE_REGISTER.json` بالاسم والحجم وSHA-256 فقط. حالة كل ملف `unverified`، وعدد الصفحات والأسئلة المعالجة صفر. لم تُفتح صفحاتها، ولم يستخرج منها نص أو صورة أو OCR. عنوان «مجاني» لا يفعّل المصدر.

## تفعيل مصدر

1. أضف بيانات المصدر من لوحة إدارة الكمي، أو سجل القائمة بأداة البيانات أدناه.
2. يراجع المسؤول الأعلى مستند السماح بتحويل المحتوى إلى بنك أسئلة واستضافته، ويضع نص الإذن أو رابط شروطه في خانة الترخيص. زر الاعتماد يسجل القرار في التدقيق. لا يستطيع مدير المحتوى أو المعلم اعتماد الترخيص.
3. بعد الاعتماد فقط، ارفق نسخة الأصل بالأداة. يتحقق الأمر من توقيع PDF وحجمه وبصمته، ثم ينسخه دون تعديل إلى التخزين الخاص.
4. اطلب مهمة الاستخراج من لوحة الإدارة، ثم شغّل الأداة في بيئة الخادم الموثوقة. تحفظ النتائج لكل صفحة، فلا تعاد الصفحات المكتملة عند الاستكمال.
5. نص الصفحة وصورتها مواد مراجعة خاصة بالمخولين. جميع الصفحات تبدأ `needs_review`، ولا يخمن المعالج إجابات أو كسورًا أو رسومًا. لا يتوفر OCR في هذه النسخة.
6. يضيف المؤلف السؤال من الصفحة، ويختار المهارة والخيارات والإجابة والشرح والمصدر والصفحة. التحقق يرفض الخيارات الفارغة والمكررة والمفتاح غير الموجود، ويعرض التكرار المحتمل بعد تطبيع العربية.
7. يقوم مراجع آخر مخول بتغيير الإصدار إلى `reviewed` ثم `approved`. إصدار جديد يعود إلى المراجعة، وتبقى إصدارات المحاولات القديمة ثابتة. الاختبارات المنشورة تقبل الإصدارات المعتمدة المرتبطة بمصدر مفعّل فقط.

## أوامر أداة المشغل

من جذر المستودع، الأمر التالي يعرض القائمة ويفحص تنسيقها فقط، دون اتصال بقاعدة البيانات أو قراءة PDF:

```powershell
node scripts/import-quant-sources.mjs
```

تستقبل الأوامر التالية `DATABASE_URL` من بيئة الخادم، ولا تطبعه أو تقرأ ملف أسرار تلقائيًا. يلزم معرف مستخدم فعّال بدور `SUPERADMIN`. لا تشغّلها على الإنتاج قبل إذن المالك.

```powershell
node scripts/import-quant-sources.mjs --register --actor SUPERADMIN_UUID
node scripts/import-quant-sources.mjs --attach SOURCE_UUID --file 'C:\private\original.pdf' --actor SUPERADMIN_UUID
node scripts/import-quant-sources.mjs --extract SOURCE_UUID --max-pages 50 --actor SUPERADMIN_UUID
```

لإعادة الصفحات الفاشلة فقط، أضف `--retry-failed`. تستمر الصفحات غير المعالجة تلقائيًا عند إعادة أمر الدفعة.

الإعدادات الاختيارية:

| متغير البيئة | الاستخدام |
| --- | --- |
| `QUANT_SOURCE_STORAGE_PATH` | مسار مطلق لتخزين خاص، خارج مجلدات الواجهة العامة والبناء. الافتراضي `.local/quant-sources`، وهو مستثنى من Git. |
| `QUANT_PYTHON_BIN` | مسار Python مع حزمة `pypdf`. الافتراضي `python`. |
| `QUANT_PDF_RENDER_BIN` | مسار Poppler `pdftoppm` لتوليد صورة الصفحة الخاصة. الافتراضي `pdftoppm`. |

يحتاج التخزين إلى قرص مستمر عند نشر عامل الاستخراج. لم يضف هذا العمل إعداد نشر أو قرصًا خارجيًا.

## حدود الاستخراج الحالية

المعالج يجهّز النص الخام وصورة الصفحة، مع حماية الترخيص والتحقق من البصمة وحفظ التقدم. لا يحتوي محللًا دلاليًا جرى التحقق من جودته على هذه المصادر؛ تحويل الصفحة إلى حقول سؤال ومراجعة العينة عمل بشري حاليًا. بعد إثبات الترخيص، تراجع عينة موزعة لا تقل عن 50 صفحة أو 5% من المصدر، أيهما أكبر (أو جميع الصفحات إذا كان المصدر أصغر)، وتوثق نتائجها قبل معالجة كاملة. لا تظهر أرقام أسئلة مستخرجة أو معتمدة حتى تسجل فعليًا في البنك.

تقارير المصدر تحسب أعداد الصفحات والأسئلة المعتمدة والمحتاجة للمراجعة والتكرارات والفشل من الجداول. ربط مصدر ثانٍ بالسؤال إجراء صريح للمسؤول؛ لا تحذف النسخ المكررة تلقائيًا. نصوص الصفحات والصور ومفاتيح الإجابات تبقى داخل واجهات الإدارة المخولة، ولا تدخل السجلات العامة.
