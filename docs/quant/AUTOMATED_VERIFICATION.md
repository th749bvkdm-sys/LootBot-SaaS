## ما تغطيه الاختبارات الجديدة

- عضوية الطالب الفعلية، نطاق المدرسة، منع صلاحيات إدارة المحتوى عن الطالب، ورفض الطلبات التي تفتقد CSRF.
- تسجيل بيانات مصدر غير مفعل دون استخراج، رفض استخراج أو إدخال سؤال منه، ورفض اعتماد ترخيص فارغ أو تغييره بواسطة طالب.
- إدخال الملف نفسه بالـ SHA-256 يعيد السجل الموجود دون تكرار؛ لا يفترض النظام أن اسم «مجاني» يسمح بالنشر.
- تطبيع العربية والأرقام، الخيارات الفارغة أو المتكررة، والمفتاح الصحيح غير الموجود.
- فصل صلاحية الكتابة عن الاعتماد، الانتقال من المراجعة إلى الاعتماد، ومنع نشر إصدار غير معتمد.
- المؤقت محسوب في الخادم، وتبقى مفاتيح الحل والشرح محجوبة في واجهة المحاولة النشطة.
- تغيير الإجابة وإلغاؤها، عد تغييراتها، علامة المراجعة، التنقل، واستعادة الحالة المحفوظة. الكتابة بإصدار قديم تعيد 409.
- استعادة الخطوط المحفوظة لكل سؤال، منع قراءتها من طالب آخر أو معلم أو المسؤول الأعلى، ورفض الضغط غير الصالح أو أكثر من 12,000 نقطة في المسودة.
- بقاء محاولة الطالب مرتبطة بإصدار السؤال الأصلي عندما يغير المسؤول بنك الأسئلة لاحقًا.
- تصحيح مثال فيه صحيح واحد وخاطئ واحد وسؤال دون إجابة: الدقة 1/2، والإنجاز 2/3. التسليم المتكرر لا يضيف محاولة أو يغير الإجابات.
- انتهاء الوقت يغلق المحاولة بصورة محفوظة قبل الرد على طلب الإجابة المتأخر. تم تشغيل دالة العامل الخلفي مباشرة للتحقق من إغلاق محاولة دون طلب من واجهة الطالب.
- منع الرجوع عندما لا يسمح الاختبار به، وسياسات الإظهار الأربع. `after_each` يكشف الحل من endpoint النتيجة للأسئلة المجاب عنها فقط، و`after_deadline` يحجب النتيجة حتى موعدها.
- التحليل يعتمد على الإجابات الفعلية ويستخدم `(correct+1)/(attempted+2)`؛ لا يصنف العينة الصغيرة كضعف. كل دليل توصية تابع لمحاولات الطالب نفسه.
- الأخطاء المتكررة تربط معرف السؤال الثابت بمحاولتين خاطئتين معروفتين، وتستبعد سياسة `never` من تفاصيل الخطأ المتكرر.
- حذف محاولة يزيل مسوداتها بالتبعية ويسجل العملية في التدقيق. لا يستطيع طالب آخر حذفها.
- تعليق ترخيص المصدر يمنع إنشاء محاولات جديدة ونشر اختبارات مرتبطة بإصداراته.

## فحص حجم البنك

أنشأ اختبار الأداء **2,000 سؤال أصلي تجريبي** داخل قاعدة مؤقتة، ثم تحقق من أن metadata تعيد العدد المجمع دون نقل نصوص الأسئلة، وأن صفحة الإدارة لا تتجاوز 500 سؤال.

في آخر تشغيل، استغرق طلب metadata نحو **67ms** على هذه البيئة المحلية أثناء تشغيل أوامر أخرى. هذا قياس محلي واحد عبر PGlite؛ لا يمثل أداء استضافة الإنتاج أو شبكة الجوال.

## تشغيل الاختبارات مجددًا

من جذر checkout:

```powershell
pnpm --filter @workspace/api-server test
pnpm run typecheck
pnpm --filter @workspace/api-server build
pnpm --filter @workspace/lootbot build
```

ومن مجلد `artifacts/api-server`:

```powershell
node tests/run-teacher-local.mjs tests/teacher-integration.ts
node tests/run-teacher-local.mjs tests/learning-integration.ts
node tests/run-teacher-local.mjs tests/education-integration.ts
node tests/run-teacher-local.mjs tests/quant-integration.ts
```

يتحقق runner من تطبيق 0010–0016 على مخطط قديم محلي، ويطبق 0016 مرتين، مع الحفاظ على حساب التاجر القديم. لا يشير إلى قاعدة الإنتاج.

## حدود التحقق

- لم تُفتح ملفات PDF الثلاثة المرفقة، ولم تُستخرج نصوصها أو صورها أو أسئلتها؛ حالة مصادرها `unverified`، وعدد الصفحات المعالجة والأسئلة المستوردة منها **صفر**.
- لا تُثبت اختبارات المؤشر والواجهة استعمال قلم Apple Pencil على iPad فعلي. يلزم جهاز فعلي لتأكيد خصائص العتاد وراحة الكتابة.
- صفحة `__preview/quant-network` المحلية تختبر فشل طلب حفظ بإرجاع HTTP 503 ثم الاستعادة. لا تقطع الإنترنت الفعلي عن الجهاز.
- لم ينفذ هذا العمل commit أو push أو نشرًا خارجيًا.
