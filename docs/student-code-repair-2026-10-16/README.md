# إصلاح رموز دخول الطلاب — 16 أكتوبر 2026

## السبب والإصلاح

كانت خدمة إصدار الرمز تشترط ارتباط الفصل مسبقًا بمدرسة، رغم أن المعلم يستطيع إنشاء فصل مستقل. لذلك كان النموذج يسمح بالطلب ثم يعرض «اربط فصلًا نشطًا بالمدرسة أولًا».

أصبح إصدار أول رمز يجهّز نطاقًا تعليميًا خاصًا بهذا الفصل المستقل داخل المعاملة نفسها. يُقفل صف الفصل وتُعاد قراءة حالته لمنع إنشاء أكثر من نطاق عند تزامن الطلبات. لا يُلحق الفصل بمدرسة أخرى، ولا تُمنح أدوار إدارية إضافية. الفصول المرتبطة بمدارس تحتفظ بارتباطها الحالي، والفصول المؤرشفة والمدارس غير النشطة تظل مرفوضة.

## تبسيط الواجهة

1. يُختار أول فصل نشط تلقائيًا، وتُخفى الفصول المؤرشفة من الاختيار.
2. يُكتب اسم الطالب فقط، ثم يُضغط «إنشاء رمز الدخول».
3. يظهر الرمز مع زر النسخ وصفحة دخول الطالب، وصلاحية افتراضية 30 يومًا.

نُقلت الصلاحية إلى «خيارات إضافية» مع 7 أو 30 أو 90 يومًا. أصبح الاسم مطلوبًا في المتصفح، وتظهر حالة تحميل وفشل جلب الفصول بوضوح. بقيت الرموز العشوائية القوية المكونة من 32 خانة كما هي، ويُخزّن تجزؤها فقط؛ لم تتغير الرموز القائمة أو شروط دخول الطالب أو الإلغاء والتجديد.

## نتائج التحقق

- `auth-integration`: 9 اختبارات ناجحة، صفر إخفاق أو تخطٍّ، بما في ذلك اختبار الأب. أُضيف اختبار إصدار الرمز لفصل مستقل، وعزل نطاقه وإعادة استخدامه دون تكرار، وعدم إضافة منح للمعلم، ورفض الفصل المؤرشف والاسم الفارغ والمستخدم غير المخوّل، ثم الدخول بالرمز ووصول الطالب لفصله الصحيح.
- `education-integration`: 6 اختبارات ناجحة، صفر إخفاق أو تخطٍّ، بما في ذلك اختبار الأب.
- فحص الأنواع على مستوى المستودع: ناجح.
- بناء واجهة LootBot والخادم: ناجح. تبقى تحذيرات Vite غير المانعة السابقة بخصوص sourcemap وحزم أكبر من 500 كيلوبايت.
- بالمتصفح: إنشاء طالب من فصل غير مرتبط، ظهور رمز 30 يومًا، مطابقة النسخ للرمز المعروض، الدخول عبر صفحة الطالب بالرمز الجديد والوصول إلى فصل مستقل صحيح.

أوامر إعادة التحقق، من جذر المشروع:

```powershell
corepack pnpm run typecheck
corepack pnpm --filter @workspace/lootbot run build
corepack pnpm --filter @workspace/api-server run build
```

ومن `artifacts/api-server`:

```powershell
node tests/run-teacher-local.mjs tests/auth-integration.ts
node tests/run-teacher-local.mjs tests/education-integration.ts
```

السجلات في المجلد نفسه. قاعدة الفحص والمعاينة محلية مؤقتة؛ لم يُنشأ طالب أو مدرسة أو رمز في قاعدة الموقع الفعلي.
