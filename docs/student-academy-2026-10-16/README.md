- جلسة تركيز دقيقة واحدة: الانتقال بين الصفحات ثم احتساب الدقيقة بعد انتهاء المؤقت وظهور الوسام المستحق.

- مراجعة الأوضاع الثلاثة واستمرار الاختيار، وتحسين تباين النص في الوضع الفاتح.
- لم تظهر رسائل خطأ في سجل المتصفح النهائي الذي تمت مراجعته.

هذه مراجعة عبر أحجام عرض في متصفح الجهاز، وليست تجربة على iPhone أو iPad أو Safari فعلي. القراءة الصوتية في STEP تستخدم أصوات المتصفح عند توفرها مع نص بديل؛ لم يُتحقق من صوت مسموع على كل نظام.

## التشغيل وإعادة الفحوص

من جذر مساحة العمل، مع Node وpnpm المثبتين:

```powershell
$env:EDUCATION_PREVIEW_PORT = '5194'
corepack pnpm education:preview
```

يفتح الرابط `http://127.0.0.1:5194/__preview/student` جلسة طالب تجريبية محلية. تُنشأ قاعدة مؤقتة؛ لا يُستخدم هذا الخادم للنشر العام، وتُفقد بياناته المؤقتة عند إيقافه. اختيار منفذ آخر يتطلب تغييره في المتغير وفي الرابط.

```powershell
corepack pnpm run typecheck
corepack pnpm --filter @workspace/lootbot run build
corepack pnpm --filter @workspace/api-server run build
```

من `artifacts/api-server`، لتكرار المجموعات الست كل واحدة على قاعدة مستقلة:

```powershell
node tests/run-teacher-local.mjs tests/auth-integration.ts
node tests/run-teacher-local.mjs tests/student-academy-integration.ts
node tests/run-teacher-local.mjs tests/student-study-integration.ts
node tests/run-teacher-local.mjs tests/quant-notebook-integration.ts
node tests/run-teacher-local.mjs tests/quant-integration.ts
node tests/run-teacher-local.mjs tests/education-integration.ts
```

## ما يلزم قبل نشر مستقبلي

دمج ملفات التحديث مع نسخة النشر الحالية بعناية لأن مساحة العمل تتضمن تعديلات سابقة، ثم إعادة البناء والفحوص وتشغيل `corepack pnpm db:migrate` باستخدام متغيرات بيئة الاستضافة. يجب التحقق من تضمين الترحيلين 0018 و0019 في خطوة ما قبل النشر. لم تُغيّر إعدادات Railway أو GitHub لهذا التحديث، ولم تُطبّق الترحيلات على الإنتاج.

لم تُنقل مسودات أو ملفات PDF الخاصة بمعاينة المفكر إلى الإنتاج. إضافة الأسئلة أو اعتمادها في بيئة أخرى يتبع مسار الاستيراد والمراجعة والترخيص القائم. الاختبارات والمزامنة والغرف تحتاج اتصالًا؛ التنزيل الحالي مخصص للدروس والأمثلة وليس تطبيقًا كاملًا دون إنترنت.
