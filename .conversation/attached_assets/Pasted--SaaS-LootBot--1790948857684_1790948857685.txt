أريد منك بناء مشروع SaaS احترافي وضخم جدًا من الصفر بالكامل باسم:

# LootBot 🚀
منصة إنشاء وإدارة متاجر Telegram

==================================================
1. فكرة المشروع
==================================================

أريد بناء منصة SaaS تسمح لأي شخص بإنشاء متجر Telegram احترافي خاص به وإدارته من لوحة تحكم ويب.

الفكرة:
العميل يسجل في المنصة
↓
ينشئ متجرًا
↓
يربط Telegram Bot Token الخاص بالمتجر
↓
يضيف المنتجات
↓
يحدد الأسعار والمخزون والضمان
↓
يحدد طرق الدفع
↓
يفعل نظام الطلبات
↓
يفعل الكوبونات
↓
يفعل النقاط
↓
يفعل الإحالات Referral
↓
يفعل VIP
↓
يحصل على متجر Telegram جاهز للعمل

المنصة نفسها هي المنتج الذي سأبيعه لأصحاب المتاجر.

لا أريد مشروع Demo أو Prototype بسيط.
أريد مشروعًا حقيقيًا منظمًا وقابلًا للتوسع والإنتاج.

==================================================
2. الهدف التجاري
==================================================

LootBot عبارة عن SaaS باشتراك شهري.

أريد أن يستطيع صاحب متجر شراء اشتراك واستخدام المنصة لإنشاء متجر Telegram خاص به.

مثال:
عميل اسمه Ahmed
يدخل LootBot
يسجل حسابًا
ينشئ متجر Ahmed Store
يربط Telegram Bot Token
ثم يحصل على بوت @AhmedStoreBot

ويصبح لديه:
- منتجات
- أقسام
- طلبات
- عملاء
- كوبونات
- نقاط
- إحالات
- VIP
- دعم
- إشعارات
- إحصائيات
- إعدادات

==================================================
3. مهم جدًا
==================================================

لا تبنِ مشروعًا شكليًا.
لا تستخدم بيانات وهمية في الوظائف الأساسية.
كل شيء يجب أن يكون مربوطًا بقاعدة بيانات حقيقية.
يجب أن تكون جميع العمليات Create / Read / Update / Delete تعمل فعليًا.

إذا كانت هناك ميزة لا يمكن تشغيلها بدون API خارجي، اجعلها مبنية بطريقة صحيحة بحيث يمكن إضافة الـ API لاحقًا، ولا تكسر المشروع.

==================================================
4. التقنية المطلوبة
==================================================

Backend:
Python 3.11+

Telegram:
python-telegram-bot

Database:
SQLite في البداية، مع تصميم يسمح بالانتقال لاحقًا إلى PostgreSQL.

Web Dashboard:
FastAPI + Jinja2

Frontend:
HTML + CSS + JavaScript
يمكن استخدام Bootstrap أو Tailwind CDN.

HTTP:
httpx

Environment:
python-dotenv

Security:
bcrypt أو passlib

ORM:
SQLAlchemy

Validation:
Pydantic

Scheduling:
APScheduler أو asyncio tasks

Logging:
Python logging
