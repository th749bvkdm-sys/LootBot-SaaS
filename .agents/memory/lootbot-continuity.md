name: LootBot continuation constraints
description: User requirements for continuing the existing LootBot project safely.
---

Continue from the existing LootBot project. Do not rebuild it from scratch, remove or replace existing files, or create a separate replacement project. Keep API keys and other secrets out of source code; use Replit Secrets or environment variables.

**Why:** the user explicitly set these limits for this project.

**How to apply:** preserve the current repository and stack, make focused changes in place, and use the secure environment-secrets flow for credentials.
